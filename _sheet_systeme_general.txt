FORMULES GÉNÉRALES (n entier, positif ou négatif) |  |  |  |  |  |  |  |  |  | 
Somme suite A(k,n) = (alphaA(k)/2) * k^n − offsetA(k) |  |  |  |  |  |  |  |  |  | 
Somme suite B(k,n) = (alphaB(k)/2) * k^n − offsetB(k) |  |  |  |  |  |  |  |  |  | 
alphaA(k) = 2*(k^4 − k^2 + 1) / [(k−1) * k^3] |  |  |  |  |  |  |  |  |  | 
alphaB(k) = k * alphaA(k) |  |  |  |  |  |  |  |  |  | 
offsetA(k) = k / (k−1) |  |  |  |  |  |  |  |  |  | 
offsetB(k) = (k^7 − k^6 + k) / (k−1) |  |  |  |  |  |  |  |  |  | 
À n=10 : Digamma = Somme A ± A(7 ou 8); les quatre possibilités servent uniquement à déterminer l’ancrage premier du rapport. |  |  |  |  |  |  |  |  |  |
