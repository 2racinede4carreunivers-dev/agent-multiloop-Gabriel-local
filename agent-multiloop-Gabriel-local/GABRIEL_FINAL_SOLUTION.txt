# ✅ GABRIEL POWERSHELL ISE - SOLUTION FINALE

## 🎯 LE PROBLÈME DÉCOUVERT

Quand vous lancez Gabriel depuis **PowerShell ISE**:
1. Les conteneurs Docker restent actifs en arrière-plan
2. Le port 8080 reste occupé même après fermeture du terminal
3. **Tuer le processus = Ferme Docker Desktop complètement**
4. Cycle infini: plus rien ne fonctionne

## ✅ LA SOLUTION: Utiliser `gabriel.ps1`

Au lieu de gérer Docker manuellement, utilisez le script PowerShell qui:
- ✅ Démarre/arrête Gabriel proprement
- ✅ Gère les conteneurs sans risque
- ✅ Ne ferme jamais Docker Desktop
- ✅ Libère le port 8080 correctement

## 🚀 UTILISATION SIMPLE

### 1. Ouvrir PowerShell ISE

Appuyez sur `Win + R`, tapez `powershell_ise` et appuyez sur Entrée

### 2. Naviguer au dossier

Dans PowerShell ISE, exécutez:
```powershell
cd C:\agent-multiloop-Gabriel-local-final\agent-multiloop-Gabriel-local
```

### 3. DÉMARRER Gabriel

```powershell

```

**Résultat:**
```

[Info] Lancement des conteneurs Docker...
[Success] Conteneurs lances
[Info] Attente du demarrage complet (20 secondes)...
[Success] GABRIEL ACCESSIBLE: http://localhost:8080
```

Puis accédez à: **http://localhost:8080**

### 4. UTILISER Gabriel

Travaillez normalement avec Gabriel...

### 5. ARRÊTER Gabriel

Dans PowerShell ISE, exécutez:
```powershell

```

**Résultat:**
```

[Info] Arret des conteneurs Docker...
[Success] Conteneurs arretes proprement
[Success] Port 8080 libere
```

### 6. Fermer PowerShell ISE

Maintenant vous pouvez fermer PowerShell ISE sans crainte!

## 🐛 TROUBLESHOOTING

### Erreur: "Port 8080 already allocated"

**Cause:** Reste des conteneurs d'une session précédente

**Solution:**
```powershell
.\gabriel.ps1 stop
Start-Sleep -Seconds 5
.\gabriel.ps1 start
```

### Erreur: "Docker Desktop: NON REPONDANT"

**Cause:** Docker Desktop s'est fermé

**Solution:**
1. Relancer Docker Desktop manuellement
2. Puis: `.\gabriel.ps1 start`

### Gabriel ne répond pas sur http://localhost:8080

**Cause:** Délai insuffisant

**Solution:**
1. Attendre 30 secondes au lieu de 20
2. Ou consulter: `.\gabriel.ps1 logs`

### "Cannot find path" ou "Permission denied"

**Cause:** PowerShell ne peut pas exécuter les scripts

**Solution:**
```powershell
# Exécuter une seule fois:
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope CurrentUser
```

## 💡 ASTUCE: Créer un Raccourci

Pour lancer Gabriel directement depuis le bureau:

### 1. Créer `demarrer-gabriel.bat`

Créez un fichier dans `C:\agent-multiloop-Gabriel-local-final\agent-multiloop-Gabriel-local\` nommé `demarrer-gabriel.bat`:


- Clic droit sur `demarrer-gabriel.bat`
- "Envoyer vers" → "Bureau"
- Double-cliquez le raccourci pour démarrer Gabriel!
