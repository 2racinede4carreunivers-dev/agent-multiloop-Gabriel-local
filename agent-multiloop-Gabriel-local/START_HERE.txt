================================================================================
                         QUESTIONS FRÉQUENTES
================================================================================

Q: Pourquoi pas port 9000?
R: Docker Desktop backend l'utilise. Conflit inévitable. Port 8080 = safe.

Q: Et si je ferme PowerShell ISE sans faire .\gabriel.ps1 stop?
R: Les conteneurs restent actifs et le port reste occupé. Redémarrage difficile.
   TOUJOURS faire .\gabriel.ps1 stop avant de fermer!

Q: Puis-je tuer le processus Docker qui écoute le port?
R: NON! Cela ferme Docker Desktop complètement. Script gère tout à votre place.

Q: Gabriel met combien de temps à démarrer?
R: 20-30 secondes généralement. Attendre avant d'accéder à http://localhost:8080

Q: Comment voir les logs Gabriel?
R: .\gabriel.ps1 logs
