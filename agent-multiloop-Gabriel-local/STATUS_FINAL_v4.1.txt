Q: Pourquoi --no-cache est obligatoire ?
A: Car les modifications au docker-compose.yml et main_cli.py doivent etre
   recompilees dans l'image Docker. Sans --no-cache, Docker utilise le cache
   et ne voit pas les modifications.

Q: Les logs Ollama disparaissent completement ?
A: Non, ils sont toujours generes mais rediriges vers des fichiers Docker
   au lieu d'etre affichés en terminal. Vous pouvez les voir avec :
   $ docker logs ollama

Q: Pytest affiche toujours 0/8 err apres redemarrage ?
A: Verifiez que le volume tests est bien monte :
   $ docker-compose exec llm-agent-multiloop-run ls /home/agent/app/tests
   Devrait afficher les fichiers de test (pas d'erreur).

Q: Puis-je tester pytest directement ?
A: Oui, tapez dans Gabriel : Philippe > ci
   Doit afficher le rapport complet des tests.

Q: Comment rollbacker en cas de probleme ?
A: Voir REDEMARRAGE_v4.1.md → "Rollback" section
   Essentiellement : git checkout HEAD -- [fichiers] + rebuild

Q: Ou sont stockes les logs Ollama maintenant ?
A: Dans les fichiers Docker json-file driver. Visibles via :
   $ docker logs ollama
   ou via Docker Desktop UI sous l'onglet "Logs" du conteneur
