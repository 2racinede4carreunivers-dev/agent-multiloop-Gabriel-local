┌─ PROBLEM 1 : LOGS OLLAMA PARASITES A L'ENTETE ──────────────────────────────┐
│                                                                                │
│ AVANT :                          │ APRES :                                    │
│ ─────────────────────────────── │ ─────────────────────────────────────────  │
│ ollama | time=2026-09-05T...   │ +======================================+   │
│ ollama | level=INFO source=...  │ | MULTI-LOOP MATH AGENT - Gabriel v4.0 │   │
│ ollama | msg="server config"... │ | Methode Spectrale * Isabelle/HOL    │   │
│ ollama | (30+ autres lignes)    │ +======================================+   │
│                                 │                                            │
│ [POLLUTION VISUELLE]            │ [INTERFACE PROPRE & PROFESSIONNELLE]      │
│                                                                                │
│ CAUSE :                                                                        │
│  - Logs Ollama envoyes a stdout du conteneur Docker                           │
│  - Affichage non-controlable en terminal                                      │
│  - Interfere avec le banner de Gabriel                                        │
│                                                                                │
│ SOLUTIONS APPLIQUEES :                                                         │
│  1. ✓ Redirection logs via docker-compose logging driver (json-file)         │
│  2. ✓ Configuration OLLAMA_DEBUG=false (moins verbeux)                        │
│  3. ✓ Delai 0.5s au demarrage de Gabriel (stabilisation Ollama)              │
│                                                                                │
│ FICHIERS MODIFIES :                                                            │
│  • docker-compose.yml (services: ollama, ollama-init, llm-agent-multiloop)   │
│  • main_cli.py (delai au demarrage + logging)                                 │
│                                                                                │
│ RESULTAT :                                                                     │
│  ✓ Interface CLI PROPRE au demarrage de Gabriel                              │
│  ✓ Logs Ollama rediriges vers fichiers Docker (accessibles via `docker logs`)│
│  ✓ Aucune perte de fonctionnalite                                             │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
