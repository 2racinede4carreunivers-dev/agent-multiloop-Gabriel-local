# TeX Quality Pipeline (CA/QC + Semantic Guard)

This module improves prose quality in LaTeX files while preserving meaning.

## What it guarantees

- It only edits prose lines under strict safety filters.
- It skips math blocks and command-heavy lines.
- It enforces a semantic acceptance gate (default: 9.6/10).
- It computes a global semantic score (before vs after) and a final acceptance verdict.
- It keeps source attribution for terminology replacements.
- It does not touch HOL files (`.thy`).

## Files

- `quality_pipeline.py`: main correction pipeline.
- `style_profile.py`: builds an author style profile from existing prose.
- `termbase_ca_qc.csv`: preferred terms with source attribution (TERMIUM/GDT references).

## Usage

Build your style profile first:

```bash
python scripts/tex_quality/style_profile.py \
  --input src/tex/espace_de_philippot.tex \
  --output qa_output/style_profile_espace_de_philippot.json
```

Run correction in dry-run mode:

```bash
python scripts/tex_quality/quality_pipeline.py \
  --input src/tex/espace_de_philippot.tex \
  --output qa_output/espace_de_philippot.corrected.tex \
  --report qa_output/espace_de_philippot.quality_report.json \
  --threshold 9.6 \
  --language fr-CA \
  --dry-run
```

Run correction and write corrected file:

```bash
python scripts/tex_quality/quality_pipeline.py \
  --input src/tex/espace_de_philippot.tex \
  --output qa_output/espace_de_philippot.corrected.tex \
  --report qa_output/espace_de_philippot.quality_report.json \
  --threshold 9.6 \
  --language fr-CA
```

## On terminology citations

You do not need to cite each term change inside the TeX body unless required by your publication rules.

Recommended practice:

- Keep citations in a traceability report (JSON generated by the pipeline).
- Add a brief methods note in your manuscript if needed.
- Keep source URLs and edition dates for audits.

## Report fields

- `total_edits_found`: all candidate edits detected.
- `total_edits_accepted`: candidates accepted by per-line semantic gate.
- `global_semantic_score`: document-level semantic score out of 10.
- `final_acceptance`: `true` only if global score is at least the configured threshold.

## Compliance note

Before bulk importing terminology from official resources, verify current reuse conditions from each source.
This project stores source attribution per replacement to support compliance checks.
